# Proyecto de control de stock

## Necesito crear un sistema de control de stock para los productos de mi supermercado

## tener en cuenta:

### Tecnologia:

#### PHP en PDO, Bootstrap para frontend, mySql para base de datos

#### Distribucion de los archivos utilizando el sistema vista-controlador

### Seguridad:

#### tener en cuenta la seguridad necesaria para evitar inyeccion de comandos SQL y tambien el sanitizado de rutas.

### Otros requisitos:

#### Quiero que el sistema tenga roles, un sistema de usuarios gestionado solo por el administrador (el administrador a traves de su escritorio personal (o dashboard) puede completar un formulario de usuarios y generar nuevos usuarios)

#### Quiero que el usuario administrador cuente con un dashboard y tambien una forma de administrar de manera manual el ingreso de productos al sistema, debera ser capaz tambien de hacer las cosas que hace el usuario y podra inhabilitar usuarios en el caso de que estos no se encuentren en funcion.

#### el usuario comun tendra acceso a un dashboard pero no podra agregar productos ni registrar un usuario nuevo, al realizar ventas podra informar de la venta y generar factura de la misma, la cual debe ser enviada al administrador.

#### el administrador debe validar las facturas enviadas por los usuarios
